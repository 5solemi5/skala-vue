## 1일차 · Vue Syntax

**ref 안 쓰면 화면이 안 바뀐다**
`let count = 0` 으로 두고 버튼을 눌러도 0 그대로다. 값은 올라가는데 Vue 가 모른다.
`ref(0)` 으로 감싸야 한다. 근데 `<script>` 에서는 `.value` 를 붙이고 템플릿에서는 안 붙인다.
이게 계속 헷갈려서 몇 번 틀렸다.

**v-html 은 위험하다**
`{{ }}` 는 태그를 글자로 보여주고 `v-html` 은 태그로 해석한다.
입력창에 `<img src=x onerror=alert(1)>` 넣고 확인 버튼을 눌러보니 진짜로 alert 가 떴다.
사용자가 친 걸 그대로 `v-html` 에 넣으면 안 된다.

**v-if / v-show**
개발자 도구로 보면 차이가 확실하다. v-if 는 요소가 아예 없어지고,
v-show 는 남아 있고 `display: none` 만 붙는다.

**v-once, v-memo**
처음엔 뭐가 다른지 몰랐다. v-once 는 한 번 그리고 끝, v-memo 는 지정한 값이 바뀔 때만 다시 그린다.
`v-memo="[name]"` 걸어놓고 나이 버튼을 눌러도 화면이 안 바뀌다가
이름을 바꾸니까 나이까지 같이 갱신됐다. 그제서야 이해됨.

**이벤트 객체**
인자 없이 `@click="fn"` 이면 이벤트 객체가 알아서 들어온다.
근데 인자를 넘기는 순간 사라져서 `@click="fn('회원A', $event)"` 로 직접 넘겨야 한다.
여기서 한 번 막혔다.

`.prevent` 는 브라우저 기본동작 막기, `.stop` 은 부모로 안 올라가게 막기.
이름이 비슷해서 헷갈렸는데 부모 박스에 버튼 두 개 놓고 하나만 `.stop` 걸어보니 확실해졌다.

**v-model 은 그냥 축약형**
`:value` + `@input` 을 한 줄로 쓴 것. 나란히 놓고 입력해보니 결과가 같았다.
1일차 과제에서 한글 때문에 `:value`/`@input` 을 직접 쓰는 이유도 이거였다.

다중 checkbox 는 `ref([])` 로 시작해야 한다. `ref('')` 로 두면 덮어써진다.
단일은 Boolean, 다중은 배열, radio·select 는 문자열. 요소마다 담기는 타입이 다른 게 제일 헷갈렸다.

`<input type="text">` 로 숫자 받으면 문자열이다. `typeof` 찍어보니 `"25"` 가 string.
`.number` 붙이니까 number 로 바뀜.

> 강사님 예제 2·3번은 제목만 `.number` / `.trim` 이고 실제 바인딩엔 수식어가 빠져 있었다.
> 그래서 typeof 가 계속 string 으로 나와서 한참 내 문법을 의심했다. 수식어 붙여서 고침.

## 2일차 · Composition API

**reactive 는 통째로 갈아끼우면 끊긴다**

```js
let state = reactive({ count: 0 })
state = { count: 5 } // 연결 끊김
state.count = 5 // 이렇게
```

배열도 같아서 push / splice 로만 건드려야 한다.
교재에 "현업에서는 그냥 ref 로 통일하는 추세"라고 적혀 있는데 이거 겪어보니 이해됨.
과제 코드는 ref 로 통일했다.

**computed 는 캐싱된다 — 이번 단원 핵심**

콘솔 열고 버튼 눌러보면 확실하다.

- dummy 버튼(무관한 변수) → 일반 함수 로그만 찍힘
- count 버튼(의존성) → 둘 다 찍힘

템플릿에 `{{ fn() }}` 처럼 괄호 붙여 호출하면 화면 다시 그릴 때마다 무조건 재실행된다.
1일차 과제에서 `getAdviceList(item)` 를 이렇게 써놨는데 카드가 6개니까 6번씩 돌고 있었다.
2일차 과제에서 computed 로 바꿈.

**watch 는 뭘 넘기냐가 전부다**

여기서 제일 헤맸다.

|                                 | 이전 값                  |
| ------------------------------- | ------------------------ |
| `watch(state, ...)`             | 안 됨 (현재 값과 같아짐) |
| `watch(() => state.price, ...)` | 됨                       |
| `watch(() => [...arr], ...)`    | 됨                       |

가격을 1000 → 1500 으로 올렸는데
통째로 감시한 쪽은 `이전 1500 → 현재 1500` 이 나왔다. 과거가 사라짐.
화살표 함수로 콕 집은 쪽은 `1000 → 1500` 으로 제대로 나왔다.
같은 객체를 가리키고 있어서 그렇다는 걸 나중에 알았다.

배열도 마찬가지. 통째 감시는 길이가 3/3 으로 같아지고 `[...cityList]` 스냅샷은 2→3 으로 나온다.

ref 객체는 기본적으로 하위 속성을 못 잡아서 `{ deep: true }` 를 켜거나 속성을 콕 집어야 한다.
reactive 는 통째로 감시하면 deep 이 자동.

**watchEffect**
감시 대상을 안 적는다. 콜백 안에서 읽은 변수를 알아서 등록한다.
대신 화면 켜지자마자 한 번 실행돼서, 새로고침하면 버튼도 안 눌렀는데 로그가 이미 찍혀 있다.

> 강사님 저장소의 `practices/composition/` 폴더가 처음 받았을 땐 비어 있었다.
> 교재 본문 보고 직접 만들었는데, 나중에 GitHub 원본을 다시 보니 파일이 올라와 있었다.
> 대조해보니 거의 같았다. 교재가 같은 출처라서 그런 듯.
> p.140(배열 watch)만 캡처 이미지뿐이라 코드가 없어서 그건 강사님 걸 참고했다.

## 3일차 · Vue Components

**onUnmounted 안 하면 타이머가 남는다**
onMounted 에서 `setInterval` 걸고 컴포넌트를 파괴했는데 `clearInterval` 을 안 하면
화면에서 사라져도 타이머가 계속 돈다. 파괴/부활을 반복하면 타이머가 겹쳐서 카운트가 여러 번 뛴다.
켠 건 꺼야 한다.

**props / emits**
데이터는 아래로, 이벤트는 위로. 자식이 props 를 직접 고치는 게 아니라 "이렇게 바꿔달라"고 요청만 한다.

이름 표기가 양쪽에서 다르다. 자식에서 `parentData` 인데 부모 템플릿에서는 `:parent-data`.
HTML 속성이 대소문자를 구분 안 해서 자동 변환된다.

**slot**
자식이 디자인(껍데기)을 갖고 내용은 부모가 넣는다.
`<slot>` 안에 뭘 적어두면 부모가 아무것도 안 넣었을 때 그게 보인다.

Scoped slot 이 제일 헷갈렸다. 보통 부모→자식으로 데이터가 가는데
이건 자식이 가진 데이터를 부모 마크업에 빌려주는 구조다.
`<slot :text="message">` 로 보내고 `v-slot="slotBag"` 으로 받아서 `slotBag.text` 로 쓴다.

과제에서 `BaseDashboardCard` 를 만들 때, 껍데기를 한 단계 거치니까
데이터를 다시 넘겨줘야 하는 줄 알았는데 아니었다. 시각적 위치랑 스코프는 별개다.

## 4일차 · 외부 라이브러리

**Pinia**
따로 배울 문법이 아니었다. ref 가 state, computed 가 getters, 함수가 actions.
지금까지 쓰던 걸 `defineStore` 로 감싼 것뿐.

`useCounterStore()` 는 부를 때마다 새로 만드는 게 아니라 같은 인스턴스를 준다.
그래서 내비게이션 바의 단위 토글이 카드 안의 온도를 바꿀 수 있다.
props 로 하려면 App → RouterView → View → WeatherCard 까지 계속 넘겨야 하는데 그걸 건너뛴다.

라우터로 화면이 바뀌면 컴포넌트는 파괴되는데 스토어는 살아있다.
그래서 메인에서 고른 모드가 상세 페이지에서도 유지된다.

**Axios**
fetch 랑 다른 점 두 개가 편했다.
`.json()` 변환이 없고 `response.data` 에 바로 담긴다.
그리고 404·500 이 오면 알아서 예외로 던져준다. fetch 는 `response.ok` 를 직접 봐야 한다.

쿼리 스트링을 `{ params: { _limit: 3 } }` 처럼 객체로 넘길 수 있어서
문자열 이어붙이기를 안 해도 된다.

> 강사님 예제에 API 키가 소스에 그대로 적혀 있다.
> 근데 저장소가 Public 이고 Hands on 9 요구사항이 "API 키는 환경 변수로" 라서
> 처음부터 `import.meta.env` 로 썼다.

**Element Plus**
`app.use(ElementPlus)` 로 등록하면 import 없이 쓸 수 있다.
근데 `element-plus/dist/index.css` 를 빼먹으면 스타일이 하나도 안 먹는다. 이거 때문에 잠깐 헤맸다.

`ElMessageBox.confirm` 이 Promise 를 준다. 확인은 `.then`, 취소는 `.catch`.
취소를 catch 로 받는 게 어색했는데 "사용자가 거부했다"를 예외로 보는 거라고 생각하니 납득됐다.

> 예제의 다운로드 시작 함수에 `if (isDownloading.value) return (isDownloading.value = true)` 가 있다.
> return 뒤에 대입이 붙어 있어서 진행 중일 때 빠져나가면서 값을 다시 true 로 만든다.
> 그리고 정작 처음 실행할 때는 true 로 바꿔주는 줄이 없어서 로딩 표시가 안 켜진다. 두 줄로 나눠 고침.

**ESLint**
잔소리라고 생각했는데 실제로 돌려보니 죽은 코드를 잡아줬다.
Tailwind 로 바꾸면서 `Badge` 사용을 뺐는데 import 문만 남아 있던 걸 찾아냈다. 눈으로는 못 봤을 것 같다.

shadcn 컴포넌트 이름(`Button`, `Card`)이 `vue/multi-word-component-names` 랑 부딪혔다.
전체를 끄면 내가 만드는 컴포넌트에도 규칙이 안 먹으니까 `src/components/ui/**` 폴더만 예외로 뒀다.

**Prettier**
교재는 백틱이 어떻게 변환되는지 보라고 하는데, 실제로 바뀐 건 공백이랑 세미콜론뿐이었다.
백틱은 그대로다. Prettier 는 템플릿 리터럴을 따옴표로 안 바꾼다.

ESLint 는 코드가 옳은지, Prettier 는 보기 좋은지를 본다.
설정에 `eslint-config-prettier` 가 들어있는 것도 둘이 서식 문제로 안 싸우게 하려는 거였다.

**환경 변수**
`VITE_` 접두사가 붙은 것만 클라이언트에 노출된다. 없으면 undefined.

빌드해놓고 `grep` 해보니 값이 문자열로 그대로 박혀 있었다.
런타임에 읽는 게 아니라 빌드할 때 치환되는 거였다. 배포 후에 값만 바꿀 수 없고 다시 빌드해야 한다.

`npm run build:staging` 하면 터미널에 `building client environment for staging` 이 찍힌다.
빌드 결과물에 `api-stage.skcc.com` 이, 그냥 `build` 하면 `api-prod.skcc.com` 이 들어간다.

**빌드**
`dist/assets/index-CWma_k0b.js` 처럼 해시가 붙는다. 내용이 바뀌면 해시도 바뀌어서 캐시 문제가 안 생긴다.

라우터에 걸어둔 지연 로딩이 눈에 보였다. LabView, ArchiveView, DevLogView 가 각각 별도 파일로 떨어진다.
CSS 도 라우트별로 쪼개져 있다.

메인 번들이 1MB 를 넘는다. Element Plus 를 전역 등록해서 안 쓰는 것까지 다 들어간 탓이다.
실무면 필요한 것만 불러오게 줄여야 할 부분.
