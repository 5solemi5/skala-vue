# SKALA 오늘의 채비

> 같은 하늘, 다른 하루

**배포** : (준비 중)

---

## 이 서비스가 하는 일

날씨앱은 "내일 비 20mm"까지만 알려준다. 그다음은 각자 알아서 판단해야 한다.
그런데 같은 예보를 보고도 준비해야 하는 건 사람마다 다르다.

| 오늘 날씨 | 아버지 (자동차 정비소) | 할머니 (농사) |
|---|---|---|
| 습도 88% | 도장 걸면 백화가 생긴다 → 오늘은 미룬다 | 잎에 물기가 오래 남는다 → 곰팡이병 조심 |
| 최저 2℃ | 배터리 방전 출동이 몰린다 → 재고 확인 | 서리 위험 → 오늘 밤 피복하거나 수확을 앞당김 |

| 오늘 날씨 | 나 (자전거) | 주말 경기 (야구) |
|---|---|---|
| 강수확률 70% | 노면이 젖으면 제동 거리가 늘어난다 → 두고 간다 | 우천 취소 가능성 → 표를 미리 정리한다 |
| 풍속 8m/s | 옆바람에 중심을 잃는다 → 오늘은 아니다 | 뜬공 판단이 어려운 날 |

같은 숫자를 챙기는 사람에 따라 다르게 읽어주는 게 이 서비스다.

**왜 만들었나** — 아버지가 자동차 정비소를, 할머니가 농사를 하신다.
두 분 다 아침마다 날씨를 확인하시는데 어느 앱도 "그래서 오늘 뭘 하시라"는 말은 안 해준다.
매일 전화로 물어볼 수도 없어서 대신 봐 주는 화면을 만들었다.
만들다 보니 날씨로 하루가 바뀌는 사람이 두 분만은 아니어서 자전거와 야구까지 넷으로 늘렸다.

## 기능 정리

**1. 누구의 오늘인지 고르기**
화면 맨 위에서 아버지(자동차 정비소) / 할머니(농사) / 나(자전거) / 주말 경기(야구) 중 하나를 고른다.
이게 첫 번째 결정이라 맨 위에 뒀다. 고른 값은 저장돼서 다음에 들어와도 그대로다.

**2. 오늘의 채비**
선택한 지역이 화면 위쪽에 크게 나온다.

- 기온, 날씨, 습도, 강수확률
- 판정 — `오늘은 아니에요` / `조심하세요` / `괜찮아요` 중 가장 무거운 것을 앞세우고 나머지는 아래에
- 왜 그런 판정인지 근거를 함께 표시 (`습도 88% — 도막에 수분이 물려 백화가 생깁니다`)
- 시간대별 막대 — 앞으로 18시간을 색으로 표시하고 괜찮은 구간을 찾아 알려준다

**3. 다른 지역 목록**
목록 위 한 줄로 전체 상황이 먼저 읽힌다 (`7곳 중 4곳은 오늘 피하시는 편이 낫습니다`).
행을 누르면 위쪽 화면이 그 지역으로 바뀌고, `상세`를 누르면 상세 화면으로 간다.

**4. 지역 추가·삭제**
목록 안에서 거르고, 없으면 그 이름으로 바로 추가할 수 있다.
한글로 검색되고(`광주` → 광주광역시 / 경기 광주시 구분), 추가한 목록은 저장된다.

**5. 상세 화면** `/weather/:cityId`
관측값 여섯 가지와 시간대별 막대, 그리고 네 사람의 하루를 나란히 비교.
같은 날씨가 아버지에게는 `조심하세요`, 나에게는 `괜찮아요` 인 것을 한눈에 볼 수 있다.

**6. 단위 전환**
헤더의 ℃ / ℉ 토글. 메인·목록·상세·시간대 막대에 한꺼번에 반영되고 저장된다.

## 만들면서 정한 것

**색은 판정에만 쓴다.**
브랜드 색을 따로 두면 화면에 색이 두 종류로 섞여서, 색이 보여도 그게 서비스 색인지
주의하라는 뜻인지 알 수 없다. 기본은 무채색(짙은 남색 잉크 + 차가운 회청 지면)으로 두고
색은 판정 세 가지에만 썼다. 화면에서 색이 보이는 곳 = 신경 쓸 곳.

**판정은 아이콘이 아니라 글자로.**
아이콘만으로는 "하지 마세요"와 "조심하세요"가 구분되지 않는다. 테두리 친 글자로 표시했다.

**결정 순서대로 배치했다.**
처음에는 검색 / 내 지역 / 모드 / 목록이 전부 같은 크기의 상자로 쌓여 있었다.
무엇부터 봐야 하는지 알 수 없어서, 실제 판단 순서인
`누구의 오늘인가 → 그래서 뭘 해야 하는가 → 다른 지역은 어떤가` 로 다시 세웠다.

**로고**
세 획이 같은 높이에서 시작하고 아래쪽 색이 차오른 만큼이 판정의 무게다.
같은 하늘을 보지만 하루가 달라진다는 서비스의 말을 그대로 형태로 옮겼다.

## 화면

| 경로               | 설명                                    |
| ------------------ | --------------------------------------- |
| `/`                | 지역별 날씨 + 모드별 오늘의 채비        |
| `/weather/:cityId` | 지역 상세 (네 가지 모드를 한 번에 비교) |
| `/about`           | 서비스 소개                             |
| `/lab`             | 수업 Code Challenge 결과물 모음         |
| `/archive`         | 과제가 단계별로 어떻게 바뀌었는지       |
| `/dev-log`         | 막혔던 것과 고쳐 쓴 코드                |

뒤의 세 개는 Hands on 5 요구사항 6번(본인의 추가 view)으로 만들었다.

## 실행

```sh
npm install
npm run dev      # http://localhost:5173
npm run lint
npm run build
```

OpenWeatherMap 키가 필요하다. 루트에 `.env.local` 을 만들고 넣는다.

```
VITE_OPENWEATHER_API_KEY=발급받은키
```

## 사용한 것

Vue 3 (Composition API) · Vue Router · Pinia · Axios · Vite
Tailwind CSS v4 + shadcn-vue · Element Plus

API 는 두 곳을 쓴다.

- **OpenWeatherMap** — 현재 기온, 날씨 상태, 습도, 풍속, 아이콘
- **Open-Meteo** — 오늘 최저기온, 강수확률 (키 불필요)

OpenWeatherMap 무료 플랜에 오늘 강수확률과 일 최저기온이 없다.
그게 없으면 방제·서리 판정을 못 해서 Open-Meteo 를 같이 부른다.

## 폴더

```
src/
├── api/weatherApi.js       두 API 를 합쳐 화면이 쓸 형태로 만든다
├── utils/
│   ├── adviceRules.js      하는 일별 판정 규칙
│   └── hourlyScore.js      시간대별 판정 (위 규칙을 그대로 재사용)
├── stores/
│   ├── configStore.js      단위(℃/℉), 하는 일
│   └── cityStore.js        내 지역 목록
├── components/
│   ├── service/            지금 서비스 화면을 이루는 컴포넌트
│   ├── exercise/           과제 단계별 결과물 (아카이브에서 그대로 사용)
│   ├── practices/          수업 Code Challenge 실습 (수업 때 쓴 그대로 둠)
│   └── ui/                 shadcn-vue 컴포넌트
└── views/
```

`practices/` 와 `exercise/` 는 수업·과제 시점의 코드를 유지했다.
지금 화면은 `service/` 아래 컴포넌트로 다시 짰다.
